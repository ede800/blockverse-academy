Fongible ou non fongible ?

Un bien est fongible quand chaque unité est interchangeable avec une autre : un billet de 10 € vaut n'importe quel autre billet de 10 €, 1 ETH vaut 1 ETH. Un bien non fongible est unique : ta place de concert (rang F, siège 12), le titre de propriété de ton appartement, une œuvre originale.

Un NFT (Non-Fungible Token) est un token qui représente un élément unique et identifiable sur une blockchain. Il ne se divise pas (on ne possède pas « 0,3 » d'un NFT classique) et chaque exemplaire a son propre historique.

Analogie

Un NFT ressemble à un acte de propriété inscrit au cadastre. Le cadastre (la blockchain) ne contient pas la maison : il dit « la parcelle n°42 appartient à Alice ». Tout le monde peut consulter le registre, et seule Alice peut signer le transfert.

Sous le capot : ce qui est vraiment sur la blockchain

Comme un token ERC-20 (module 9), un NFT n'est qu'une entrée dans le stockage d'un smart contract. La différence : au lieu de adresse → solde, le contrat garde un dictionnaire tokenId → propriétaire.

Adresse du contratIdentifie la collection (ex. 0xBC4C…f13D).
tokenIdNuméro unique au sein du contrat (#1, #2, #8817…).
Le couple des deuxEst unique au monde : c'est l'identité du NFT.
// L'essentiel du standard ERC-721 (simplifié)
interface IERC721 {
    function ownerOf(uint256 tokenId) external view returns (address);
    function balanceOf(address owner) external view returns (uint256);
    function transferFrom(address de, address a, uint256 tokenId) external;
    function safeTransferFrom(address de, address a, uint256 tokenId) external;
    function approve(address a, uint256 tokenId) external;
    function setApprovalForAll(address operateur, bool ok) external;  // ⚠ toute la collection
    event Transfer(address indexed de, address indexed a, uint256 indexed tokenId);
}
// Extension « métadonnées »
function tokenURI(uint256 tokenId) external view returns (string);   // → lien vers le JSON

Toute l'histoire d'un NFT — sa création, chaque vente, chaque transfert — est lisible publiquement grâce aux événements Transfer. Une création (mint) est simplement un Transfer depuis l'adresse zéro.

        Métadonnées modifiables
        
Si le contrat permet à l'équipe de changer le baseURI, elle peut modifier l'apparence de tous les NFT après la vente. Les projets sérieux « gèlent » leurs métadonnées (fonction freeze) une fois la collection terminée.

      


      
Le mint : comment naît un NFT

      
    
        
  • Mint public : n'importe qui appelle mint() en payant le prix fixé, jusqu'à épuisement de l'offre.
    • 
        
  • Allowlist : seules certaines adresses peuvent minter en avance. Le contrat ne stocke pas la liste entière, seulement une racine de Merkle (module 2) ; chacun fournit sa preuve de Merkle.
    • 
        
  • Reveal : on mint d'abord une image « mystère », puis les vraies métadonnées sont révélées. Pour que l'attribution des NFT rares soit équitable, on utilise un aléatoire vérifiable (VRF, module 13).
    • 
        
  • Lazy minting : le créateur signe le NFT hors chaîne ; il n'est réellement créé (et le gas payé) qu'au moment du premier achat.
    • 
        
  • Art génératif : le contrat enregistre un hash au moment du mint, et un script (parfois stocké on-chain) transforme ce hash en œuvre — exactement ce que fait la démo.
    • 
      


      
Acheter et vendre : les marketplaces

      
Une marketplace NFT (OpenSea, Magic Eden, Blur…) fonctionne en général ainsi :

      
    
        
  1. Le vendeur appelle une fois setApprovalForAll(marketplace, true) : il autorise le contrat de la marketplace à déplacer ses NFT de cette collection.
    2. 
        
  2. Pour mettre en vente, il signe un ordre hors chaîne (« je vends #42 pour 0,5 ETH jusqu'à vendredi ») : gratuit, pas de gas.
    3. 
        
  3. Quand un acheteur accepte, il envoie la transaction : le contrat vérifie la signature, puis, de façon atomique, transfère les ETH au vendeur et le NFT à l'acheteur. Les deux arrivent, ou rien ne se passe.
    4. 
      

      

        Piège classique
        
Comme un ordre de vente n'est qu'une signature, un site de phishing peut te faire signer « vendre toute ma collection pour 0 ETH ». Et une demande de setApprovalForAll sur un faux site donne à l'attaquant un accès à tous tes NFT de la collection (module 14).

      


      
Les royalties : une promesse pas toujours tenue

      
Les créateurs touchent souvent un pourcentage sur chaque revente (5 à 10 %). Le standard ERC-2981 permet au contrat d'indiquer ce pourcentage… mais pas de l'imposer : un transfert ERC-721 peut se faire sans paiement. En 2022-2023, plusieurs marketplaces ont rendu les royalties optionnelles pour attirer les traders. Certains standards plus récents restreignent les transferts aux places de marché qui les respectent, au prix d'une moindre liberté pour les détenteurs.

Usages réels et limites

      

        

          
✔ À quoi ça sert vraiment

          
    
            
  • Art numérique et provenance vérifiable
    • 
            
  • Billetterie (anti-contrefaçon, revente encadrée)
    • 
            
  • Noms de domaine (ENS : alice.eth)
    • 
            
  • Objets de jeu qu'on possède réellement
    • 
            
  • Positions DeFi (une position de liquidité Uniswap v3 est un NFT)
    • 
            
  • Certificats, adhésions, titres d'actifs réels
    • 
          

        

        

          
✖ Ce qu'il faut savoir

          
    
            
  • Posséder le NFT ≠ posséder les droits d'auteur (sauf licence explicite)
    • 
            
  • N'importe qui peut copier l'image : le NFT prouve la propriété du token, pas l'exclusivité du fichier
    • 
            
  • Marché très spéculatif : après la bulle de 2021-2022, la plupart des collections ont perdu l'essentiel de leur valeur
    • 
            
  • Liquidité faible : il faut trouver un acheteur pour ce NFT précis
    • 
            
  • Wash trading : de faux échanges gonflent les volumes affichés
    •

Seules certaines collections stockent l'œuvre entièrement on-chain (SVG, Ordinals).

        

        

          
Pourquoi un lien IPFS est-il plus fiable qu'un lien vers le serveur du projet ?

          

            
            
            
          

          
Attention : IPFS garantit l'intégrité, pas la disponibilité. Il faut que quelqu'un continue à « épingler » le fichier.

        

        

          
Acheter un NFT d'une image te donne-t-il les droits d'auteur sur l'image ?

          

            
            
            
          

          
Le NFT prouve la propriété du token ; les droits dépendent de la licence du projet.
