Un token, c'est un tableau dans un contrat

Un token n'est pas un objet qui « se déplace ». C'est une ligne dans le stockage d'un smart contract : un dictionnaire adresse → solde. Quand tu « envoies » 100 USDC, tu appelles en réalité la fonction transfer du contrat USDC, qui diminue ton solde et augmente celui du destinataire.

Conséquence pratique

Même pour envoyer un token, il faut payer le gas avec la monnaie native de la chaîne (ETH sur Ethereum). Un wallet avec 1 000 USDC et 0 ETH ne peut rien envoyer — sauf via un smart wallet qui sponsorise le gas.

Les standards ERC

Pour que tous les wallets et applications comprennent tous les tokens, Ethereum définit des interfaces standard (Ethereum Request for Comments).

// L'interface ERC-20 (simplifiée)
interface IERC20 {
    function totalSupply() external view returns (uint256);
    function balanceOf(address compte) external view returns (uint256);
    function transfer(address a, uint256 montant) external returns (bool);
    function approve(address spender, uint256 montant) external returns (bool);
    function transferFrom(address de, address a, uint256 montant) external returns (bool);
}

approve + transferFrom : le duo à comprendre

Pour qu'un DEX puisse prendre tes tokens lors d'un swap, tu dois d'abord l'autoriser (approve) à dépenser un certain montant. Le DEX appelle ensuite transferFrom. Beaucoup d'applications demandent une autorisation illimitée : si le contrat est piraté ou malveillant, il peut vider tes tokens. Pense à révoquer les autorisations inutiles (outils de type « revoke »).

Les stablecoins

Des tokens conçus pour valoir une valeur stable, généralement 1 dollar (ou 1 euro). Ils sont la colonne vertébrale de la DeFi et des paiements crypto.

En Europe, le règlement MiCA encadre les émetteurs de stablecoins depuis 2024 ; aux États-Unis, la loi GENIUS Act (2025) a posé un cadre fédéral pour les stablecoins de paiement.

Les NFT, au-delà des images de singes

Un NFT est un certificat de propriété unique sur la blockchain. Le plus souvent, l'image elle-même n'est pas stockée on-chain : le token contient un lien vers des métadonnées (sur IPFS ou un serveur). Acheter un NFT ne donne pas automatiquement de droits d'auteur sur l'œuvre.

Usages au-delà de l'art : billets d'événements, noms de domaine (ENS), diplômes et certifications, objets de jeu, positions de liquidité (Uniswap v3), adhésion à une communauté.

Autres familles de tokens

  • Gouvernance (UNI, AAVE…) : droit de vote sur l'évolution d'un protocole.
  • Liquid staking (stETH, rETH) : représentent de l'ETH staké, tout en restant utilisables en DeFi.
  • Wrapped (WETH, WBTC) : version ERC-20 d'un actif natif ou d'un actif d'une autre chaîne.
  • RWA (Real World Assets) : obligations d'État, fonds monétaires, immobilier tokenisés par des institutions financières.
  • Memecoins : tokens sans utilité autre que spéculative ou communautaire. Extrêmement risqués.

Lire une tokenomics

Avant de s'intéresser à un token, quelques questions essentielles :

  • Offre : quelle quantité existe aujourd'hui (circulante) et au maximum ? Y a-t-il de l'inflation ?
  • Répartition : quelle part est détenue par l'équipe et les investisseurs ? Quand sont-ils débloqués (vesting) ?
  • Utilité : à quoi sert le token concrètement ? Le protocole fonctionnerait-il sans lui ?
  • Contrôle : le contrat permet-il de minter à volonté, de geler des comptes, de bloquer les ventes ?
